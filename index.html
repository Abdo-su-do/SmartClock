System Architecture & Purpose

Project Overview & Core Engineering Vision

Transforming a conventional microcontroller clock into a deterministic, multi-tasking environmental station

Project Objectives

  • Ultra-Accurate Timekeeping: Hardware RTC DS1307 battery-backed clock with dual 12H/24H formats.
  • Multi-Mode Platform: 6 interactive screens (Clock, Telemetry, Alarms, Countdown, Stopwatch, Pomodoro).
  • Zero-Flicker Display: Smart differential rendering pipeline over 4x20 Character LCD.

Real-Time Challenges

  • Deterministic Concurrency: Running countdowns, alarms, and stopwatches concurrently without blocking `_delay_ms()`.
  • ADC Noise Filtering: Accurate LM35 temperature and analog humidity sampling on 10-bit successive approximation ADC.
  • Keypad Debouncing: Finite State Machine key scanning with rapid responsiveness.

Key Engineering Highlights

  • Layered Architecture: Strict separation of MCAL, HAL, and Application layers.
  • Timer0 Master Scheduler: 31.25 Hz hardware interrupt tick managing asynchronous state engines.
  • Global Settings Engine: Dynamic configuration overlay accessible instantly via the `[*]` key.

Design Principles

  • Portability & Reusability: Application algorithms are 100% target-agnostic. MCAL can be ported to STM32 or ESP32 with zero changes to App logic.
  • Information Hiding: Application never touches hardware registers (e.g., `PORTA`, `TWCR`, `ADCSRA`). All interactions pass through structured HAL APIs.
  • Static Memory Allocation: Zero heap memory allocation (`malloc`), eliminating memory fragmentation in embedded SRAM.

==================== TIME: 10:45:32 PM DATE: 28/08/2026 DAY : FRIDAY [24H]
DS1307 I2C Master Mode @ 100 kHz

Communicates over Two-Wire Interface (TWI) bus reading seconds, minutes, hours, day-of-week, date, month, and year from register addresses `0x00` through `0x06`.

Technical Implementation

  • BCD to Binary Math: Real-time conversion macros: `val = ((bcd >> 4) * 10) + (bcd & 0x0F)` for high-speed arithmetic.
  • 12H / 24H Selectable Format: Instant conversion algorithm with AM/PM indicator flag, maintained across state navigations.
  • Non-Volatile Battery Backup: CR2032 coin cell ensures continuous oscillation of the 32.768 kHz crystal during MCU power cycles.

Maintains elapsed time in standard seconds accumulator variable driven by the Timer0 31.25 Hz scheduler.

Navigation Bindings

  • [+] Key: Next Screen (1 → 2 → 3 → 4 → 5 → 6)
  • [-] Key: Previous Screen (6 ← 5 ← 4 ← 3 ← 2 ← 1)
  • [/] Key: OK / Start / Pause / Confirm Selection
  • [=] Key: Back / Cancel / Reset Counter
  • [*] Key: Open Global Settings Menu Modal

Anti-Flicker Architecture

  • No Full Screen Clears: Avoids continuous calls to LCD_Clear() which cause harsh visual strobing.
  • Dirty-Flag Buffer Rendering: Only LCD positions whose characters have physically mutated are updated over the bus.
  • Bus Bandwidth Saving: Reduces LCD command overhead by over 82%, freeing MCU execution cycles.
Real-Time Scheduling Core

Concurrency Engine: Timer0 ISR & Scheduler

31.25 Hz Deterministic Hardware Master Tick Driving Parallel Tasks Without an RTOS

Timer0 Math & Tick Generation

/* System Frequency = 8,000,000 Hz, Prescaler = 1024 */ /* Timer Tick Rate = 8,000,000 / 1024 = 7812.5 Hz */ /* 8-Bit Overflow Period = 256 Ticks */ /* Overflow Frequency = 7812.5 / 256 = 30.51 Hz (~31 Overflows/sec) */ ISR(TIMER0_OVF_vect) { static uint8_t ovf_count = 0; ovf_count++; if (ovf_count >= 31) { ovf_count = 0; system_1sec_flag = 1; // Master 1-Second Tick } }

Cooperative Multi-Task Dispatcher

  • Non-Blocking Execution: Every application engine (Stopwatch, Countdown, Pomodoro, Alarm Check) runs inside a short cooperative step function.
  • Volatile Thread Safety: Flags shared between ISR and super-loop (e.g., system_1sec_flag) are declared volatile to prevent compiler caching.
  • Guaranteed Response Time: Keypad scan executes at 50 Hz, ensuring zero missed key presses during heavy display updates.
